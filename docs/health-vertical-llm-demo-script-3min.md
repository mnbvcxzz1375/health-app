# 康复智伴三分钟黄金演示脚本

## 0:00–0:25 先定义问题

打开 `/home`，说明目标用户是“多病共存、长期用药、需要居家康复的老年人”，系统不做诊断，而是把指标、药物、报告和训练动作组合成保守决策。

## 0:25–1:05 输入证据

进入 `/upload` 展示报告保存；进入 `/devices` 展示设备数据来源；进入 `/medication` 展示当前用药。强调所有数据按用户隔离，来源和时间范围会进入病例上下文。

## 1:05–1:45 问答安全网关

进入 `/assistant`，先演示普通健康问题：回答下方展示知识来源、证据片段、不确定性和下一步。再输入“胸痛/呼吸困难”等急症关键词：确定性规则直接升级急诊，不接受模型低风险元数据降级。

## 1:45–2:25 康复计划

进入 `/rehab/smart-plan`，展示 `RehabCase` 的病例依据、风险等级、行动标签和保守计划。删除身高/体重/年龄后重新生成，展示系统进入资料补充状态，而不是伪造热量或默认动作。

## 2:25–2:50 饮食闭环

进入 `/diet/camera`，上传食物图，展示“视觉候选→食物库匹配→分量估计”。确认后写入日志；修改或删除一条记录，说明前后快照会进入 `diet_log_audits`。

## 2:50–3:00 收束边界

展示数据卡和三臂评测入口。明确当前工程测试和合成病例契约不能替代脱敏盲测、专家复核或临床验证。
