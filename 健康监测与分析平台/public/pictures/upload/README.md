# 上传资料测试图片

本目录包含用于测试"上传分析"功能的化验单/影像/检查报告图片（SVG 格式）。

## 图片清单

| 文件 | 类型 | 内容摘要 | 适用资料类型 |
|------|------|---------|-------------|
| `blood_test_report.svg` | 化验报告 | 血常规化验单：WBC↑、PLT↓、中性粒细胞↑，含参考范围和诊断意见 | lab |
| `ct_report.svg` | 影像报告 | 胸部 CT 诊断报告：双肺纹理增粗、右肺中叶斑片影，含影像所见和诊断意见 | image |
| `health_checkup.svg` | 体检报告 | 健康体检摘要：血压偏高、血糖受损、血脂异常，含血生化指标 | lab |
| `ecg_report.svg` | 检查报告 | 心电图报告：心率 88 bpm、下壁可疑心肌缺血，含波形分析 | image |

## 用途

在 `UploadPage.vue` 的"上传分析"页面中：
- 选择"影像资料"类型时，显示 CT 报告和心电图报告 2 张示例
- 选择"化验报告"类型时，显示全部 4 张示例（化验单也接受图片格式）

点击任一缩略图会自动加载示例文件到文件列表，用户确认后点击"开始分析"触发分析流程。

## 来源

这些 SVG 图片是为测试目的生成，包含医院名、日期、患者信息、指标项（含参考范围和异常标记）、诊断意见、医师签名等结构化文字信息，便于验证 OCR 文字提取和 LLM 结构化分析的完整流程。

## 引用方式

```ts
const sampleImages = [
  { name: '血常规化验单', url: new URL('../../../../pictures/upload/blood_test_report.svg', import.meta.url).href, category: '化验报告', type: 'lab' as const },
]
```

Vite 默认支持 SVG 作为 URL 字符串导入（返回文件路径），可用于 `<img :src="url">`。
