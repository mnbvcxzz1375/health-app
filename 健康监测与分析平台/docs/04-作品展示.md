# 康复智伴作品展示

## 1. 展示目标

展示当前 Beta 版本如何完成以下主链：

1. 用户上传报告并得到分析结果。
2. 用户保存报告并生成康复计划草案。
3. 用户确认后应用康复计划。
4. 用户设置用药提醒并接受系统通知。
5. 用户在康复页录制或上传视频，获得姿态纠错结果。
6. 用户使用 AI 助手进行健康问答。

## 2. 推荐展示顺序

### 2.1 登录

- 展示电脑端和手机端登录页
- 使用演示账号进入系统

### 2.2 总览

- 展示健康摘要
- 展示设备入口
- 展示已保存报告折叠区
- 打开一条报告的“全览”弹窗

### 2.3 上传分析

- 上传文字或报告文件
- 等待大模型生成结构化结果
- 点击“保留并生成康复计划”
- 展示草案生成成功后的滚动定位与高亮

### 2.4 康复计划

- 打开康复页查看新计划
- 展示计划摘要、今日动作清单、统一提醒
- 打开某个动作详情页

### 2.5 用药提醒

- 展示一组闹钟包含多药品
- 上传药盒图片识别并回填字段
- 展示全局提醒弹窗

### 2.6 动作拍摄纠错

- 在康复页进入姿态识别专区
- 上传视频或录制视频
- 展示任务状态、评分、问题与建议

### 2.7 AI 助手

- 进入全屏助手页
- 点击预设问题
- 展示流式回复和历史记录

## 3. 关键亮点

- 上传分析与康复计划联动
- 用药提醒支持多药品闹钟
- 药品识别主链与本地副链并行但隔离
- 姿态识别链支持并发任务排队
- AI 助手支持流式输出
